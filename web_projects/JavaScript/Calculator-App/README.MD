# 🧮 Calculator App

A simple and stylish calculator built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations with a clean user interface.

---

## 📌 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖ Multiplication  
- ➗ Division  
- 🟰 Instant result display  
- 🧹 Clear screen (**C** button)  
- 🔙 Remove last character (**R** button)  
- % percentage support  
- Decimal calculations  

---

## 🛠 Technologies Used

- **HTML** — structure  
- **CSS** — styling & layout  
- **JavaScript** — functionality & calculations  

---

## 📂 Project Structure

```
calculator-app/
│
├── index.html   # Main calculator layout
├── calc.css     # Styling
└── calc.js      # Calculator logic
```

---

## ▶ How to Run

1. Download or clone the project.
2. Make sure all files are in the same folder.
3. Open `index.html` in your browser.

---

## 🎮 How to Use

- Click numbers to input values.
- Click operators (+, -, *, /) to perform calculations.
- Press **=** to get the result.
- Press **C** to clear everything.
- Press **R** to delete the last character.

---

## ⚠ Note

This calculator uses JavaScript `eval()` to compute results.  
For advanced or production apps, consider safer parsing methods.

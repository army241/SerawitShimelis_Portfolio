# 📝 Todo List App

A simple and interactive Todo List web application built using **HTML**, **CSS**, and **JavaScript**.

---

## 🚀 Features

- ➕ Add a new task  
- 📅 Select a due date  
- ❌ Delete tasks  
- 📋 View all tasks dynamically  
- 🌙 Dark theme design  
- ⚡ Instant re-render after update  

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling (Grid Layout, Dark Theme)  
- **JavaScript (Vanilla JS)** – Functionality

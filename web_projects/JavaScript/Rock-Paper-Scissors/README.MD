# ✊✋✌️ Rock Paper Scissors Game

A simple **Rock Paper Scissors** web game built using **HTML, CSS, and JavaScript**.  
Play against the computer and track your wins, losses, and ties.

---

## 🎮 Features

- Interactive Rock, Paper, Scissor buttons
- Random computer move generation
- Live game result display
- Score tracking (Wins, Losses, Ties)
- Score saved using **localStorage**
- Reset score functionality
- Clean dark-themed UI

---
## 🕹️ How to Play

1. Click one of the buttons:

- ✊ Rock  
- ✋ Paper  
- ✌️ Scissors  

2. The computer will randomly choose a move.
3. The result will be displayed:
- **You win**
- **You lose**
- **Tie**
4. Your score updates automatically.

---

## 🔄 Reset Score

Click the **Reset Score** button to:

- Clear wins, losses, and ties
- Remove saved score from browser storage
